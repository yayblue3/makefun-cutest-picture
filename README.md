A chubby baby kitten hugging a pink heart, drawn by a Python program for make.fun's “Make the cutest picture” bounty, $250 in USDC.

## The picture

A big tilted head filling the frame, huge dark eyes with sparkle highlights, tiny ears with a pink bow, blush cheeks, and two front paws hugging a small pink heart on a soft warm background. One subject, nothing crowding it, so it still reads at ~300px.

## Run it

```sh
python3 main.py
```

Reads nothing, writes `/output/entry.png` (1024x1024). Locally, point it at a directory instead:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Two runs on the same input produce byte-identical output.
